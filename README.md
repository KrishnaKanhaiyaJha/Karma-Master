# 🛒 Karma Shop - E-Commerce Website

A modern and responsive **E-Commerce Website** built using **HTML, CSS, JavaScript, Bootstrap, and jQuery**. This project provides a complete online shopping frontend experience with product listings, categories, filters, cart pages, checkout pages, blog pages, and responsive UI design.

---

## 🚀 Features

* Responsive E-Commerce Website Design
* Product Categories and Filters
* Product Listing Page
* Shopping Cart Page
* Checkout Page
* Product Details Page
* Search Functionality
* Blog Section
* Sticky Navigation Bar
* Attractive UI/UX Design
* Mobile Friendly Layout

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* jQuery
* Owl Carousel
* Font Awesome
* Google Maps API

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/your-username/karma-shop.git
```

2. Open project folder:

```bash
cd karma-shop
```

3. Run the project by opening:

```bash
index.html
```
